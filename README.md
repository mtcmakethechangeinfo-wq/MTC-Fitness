# MTC Fitness Coaching

Die App von MTC Fitness Coaching: Trainingsplan, 3D-Muskelmodell und Coaching in einer Web-App, die sich auf iPhone und Android wie eine normale App auf den Home-Bildschirm legen lässt und auch ohne Internet funktioniert.

Alle Trainingsdaten bleiben auf dem Handy der jeweiligen Person. Dieses Repository enthält nur die App selbst, keine Kundendaten.

Lizenzen der verwendeten Bestandteile (three.js, Chakra Petch, BodyParts3D): siehe `LIZENZEN.txt`.
